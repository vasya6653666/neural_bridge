# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-03-20

### Added

- Initial release of CloudZero Cloud Cost Intelligence Power
- MCP server configuration for CloudZero's public endpoint
- Steering documents for cost analysis, cost dimensions, optimization, telemetry, and org context workflows
- 12 tools across 6 categories: Cost Analysis, Cost Dimensions, Organization Context, Optimization, Telemetry, and Reference
- Browser-based OAuth authentication (no API keys required)
- Data sensitivity guidelines
- Query guardrails for rate-limiting awareness
- Security considerations for organization context switching
- Trust boundary documentation in README
