# Contributing to CloudZero Cloud Cost Intelligence Power

Thank you for your interest in contributing! We welcome contributions from the community.

## How to Contribute

1. **Fork** the repository and create a feature branch from `main`.
2. **Make your changes** and ensure they follow the existing style and conventions.
3. **Test** your changes by installing the power locally from the Powers panel of NeuralBridge IDE.
4. **Submit a pull request** with a clear description of what you changed and why.

## What We Accept

- Bug fixes and corrections to steering documents
- Improvements to documentation and examples
- New steering workflows for common use cases

## What Requires Discussion First

- Changes to `mcp.json` (the MCP server endpoint)
- Changes to `POWER.md` metadata or onboarding flow
- New tool integrations

Please open an issue to discuss these before submitting a PR.

## Code of Conduct

Be respectful and constructive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
