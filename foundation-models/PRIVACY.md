# Privacy Policy

Last updated: August 9, 2026

The Foundation Models plugin runs entirely on the user's machine. It does not
collect, store, sell, or transmit personal data, source code, prompts, or usage
information.

The bundled scripts read the locally installed Apple SDK and Swift files that
the user or agent explicitly asks them to inspect or type-check. Temporary
copies created during type-checking are deleted when the command finishes. The
plugin makes no network requests and requires no account, API key, or external
service.

The agent client in which the plugin is installed may process prompts, files,
or telemetry under that client's own privacy policy. That processing is outside
the control of this plugin.

Questions about this policy can be submitted through
[GitHub Issues](https://github.com/artemnovichkov/foundation-models-plugin/issues)
or sent to [mail@artemnovichkov.com](mailto:mail@artemnovichkov.com).
