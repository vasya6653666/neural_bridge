# Mintlify for NeuralBridge

The official NeuralBridge Power for creating, maintaining, and improving [Mintlify](https://www.mintlify.com) documentation.

The Power gives NeuralBridge task-specific Mintlify guidance and access to Mintlify MCP tools. Its generated contents are maintained from the canonical agent context in the [Mintlify documentation repository](https://github.com/mintlify/docs/tree/main/agent-context).

## Installation

Install the power from the **Powers** panel in NeuralBridge IDE.
