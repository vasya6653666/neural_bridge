# Installing and launching

## The `neuralbridge` command

- The Windows installer adds the `neuralbridge` command to `PATH`.
- `neuralbridge .` opens the current folder in the IDE.
- On macOS the command is installed from the command palette: «Shell Command: Install 'neuralbridge' command in PATH».

## macOS

The application is named `NeuralBridge.app`. A macOS build is not available yet.

## Command-line tool

There is no information about a command-line tool in this reference yet. If the user asks, say that you don't have that
information and do not describe one. The `neuralbridge` command above only opens the IDE.
