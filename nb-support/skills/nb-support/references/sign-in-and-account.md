# Signing in and the account

## How sign-in works

NeuralBridge IDE has one way to sign in: with a NeuralBridge account, by confirming the device in the web account. There is
no sign-in with Google, GitHub or any cloud provider.

1. On start, the IDE shows a sign-in screen over the window with the line «An agentic IDE that helps you do your best work.»
   and the **Sign in** button.
2. After **Sign in**, the IDE opens the default browser on the device confirmation page of the web account
   (`panel.neuralbridge.ru`). The account itself is entered with email and password.
3. The IDE window shows «We will take you to your default web browser to sign in and bring you back when it's complete...»,
   a **Code** field with the code, the line «Or open this link in your browser:» with a link, and a **Cancel** button.
   The code in the window must match the code on the confirmation page.
4. Once the device is confirmed, the IDE shows «You are signed in!».

The bottom of the sign-in screen reads «By signing in, you agree to the Service Terms and Privacy Notice».

**If the browser did not open:** copy the link from the sign-in window and open it in any browser on the same machine.

## The account window

The account button is at the bottom of the Activity Bar. Its window is where the user signs out and switches the current
project.

## Projects

In NeuralBridge a project is tied to an API key: each key is a separate project with its own configuration. The account
window shows the current project and lets the user switch to another one.

## Balance

NeuralBridge accounts have a balance in rubles. Do not quote prices or plan contents: send the user to the web account.
