# Orca Security Power for NeuralBridge

Connects NeuralBridge to the [Orca Security MCP server](https://orca.security/mcp-server/), so the agent can triage alerts, explore assets and attack paths, query your cloud inventory, and track compliance using live data from your Orca account.

## Install

Install the power from the **Powers** panel in NeuralBridge IDE.

## Authentication

The power uses OAuth.
On first use, NeuralBridge opens a browser window to sign in with your Orca account.
